When it fails

Two conditions the variant depends on, both easy to miss.

judgement
  • Something must scroll under it. Over a flat canvas the blur has nothing to sample and the bar just reads as a muddier surface — use the solid default there.
  • It must be sticky or fixed (.is-sticky). A static frosted bar blurs whatever happens to sit behind it in the layout, which is usually nothing.
  • Without backdrop-filter support the bar falls back to an opaque surface rather than a washed-out translucent one — a @supports guard, so text never lands on a semi-transparent field.
  • The bottom hairline steps up to --color-border-strong: with a translucent background the boundary is the only thing separating bar from content.

05Account menu

The right end of the bar: avatar plus identity as one trigger, opening a dropdown. Showing the name and company in the bar itself — rather than an avatar alone — is what removes the duplicate identity block the sidebar used to carry.

Trigger and menu .tb-account

The trigger reads --tb-control-h like every other bar item, so it stays in the row's rhythm. .is-open holds the hover treatment while the menu is up, so the trigger does not look inert under its own dropdown.

06Bar sizes

Every item in the bar reads --tb-control-h, so the real lever is the bar: .is-sm and .is-lg retune the token and controls, search and account scale together. Per-control .sm/.lg stay available for the one-off pill, and deliberately leave the bar height alone.

Three densities .is-sm · .is-lg

56 / 60 / 72px, with 32 / 40 / 48px controls — the sm / md / lg steps of the shared height scale. The bar height tracks the control with room to breathe rather than hugging it, which is why it is set next to the token instead of derived from it.

07Mobile

Below 720px the bar collapses to three things: the menu button, the search icon and the account. The brand comes off entirely — the menu and the account already say where you are — and the language control and live clock hide as ambient status. Everything keeps the 40px control box, so no tap target shrinks.

Compact bar

The brand comes off entirely and the search pill drops to its icon, keeping the 40px control box so no tap target shrinks. The menu button and the account already identify the app, so a mark at this width would only cost room the search and primary action need. The language control and the live clock hide: they are ambient status, not worth a target at this width. The frame below carries .is-compact — the same collapse the 720px breakpoint applies, available as a modifier so a bar in a narrow container can opt in without waiting for the viewport.
