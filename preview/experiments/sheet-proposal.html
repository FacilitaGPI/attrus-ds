Sheet

O painel que sobe da borda de baixo no celular. Hoje existe só o .sheet no CSS e o DTDetailSheet, que é específico do detalhe de linha e não move nem prende o foco. A proposta é um Sheet genérico com o comportamento de diálogo completo, e o DTDetailSheet passa a ser um atalho sobre ele, sem mudar a API.

API

<Sheet
  open={boolean}
  onClose={() => void}
  title="Ordenar por"            // rótulo do diálogo (aria-labelledby)
  sub?="…"                        // linha de apoio sob o título
  eyebrow?={<Pill/>}             // acima do título — status no detalhe
  footer?={<><Button/><Button/></>}  // duas ações, secondary · primary
  closeButton?={true}             // o ✕ do cabeçalho
  dismissible?={true}             // Esc e scrim fecham; false para fluxo obrigatório
  initialFocus?={ref}             // padrão: o 1º controle, ou o item .is-on da lista
>
  {conteúdo}
</Sheet>

<SheetOption selected? icon? onSelect>Mais recentes</SheetOption>   // .sheet-opt — uma escolha, 48px

Três usos, o mesmo componente

Toque numa linha, no ícone de ordenar ou no de filtrar. Teste também com o teclado: o foco entra no painel, fica preso nele, Esc fecha e o foco volta para quem abriu.
