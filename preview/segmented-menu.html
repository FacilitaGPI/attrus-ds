Segmented control, menu, stage progress

Three small controls from the ATTRUS ONE client list: a row of choices with counts, the menu one segment opens, and the step strip in a table row.

SegmentedControl

One choice among two to four, in a row. Each segment is as wide as its label, so nothing truncates when the text changes. A segment can carry a count (mono, on the label's baseline) or open a menu (chevron). role="radiogroup"; ← and → move the choice, only the selected segment is in the tab order.

<SegmentedControl aria-label="Phase" value={v} onChange={setV}
  onMenu={(v, el) => openMenu(el)}
  options={[
    { value: 'in',  label: 'In onboarding', count: 323 },
    { value: 'out', label: 'Out of onboarding', menu: true },  // chevron; calls onMenu instead of selecting
  ]} />

Segmented or tabs? Tabs switch between views of different content. The segmented control filters the same list.

DropdownMenu · MenuItem · MenuSeparator

A generic menu that opens from any trigger. On open it focuses the selected item (or the first). ↑ and ↓ move and wrap, Esc and an outside click close it and return focus to the trigger. An item has a dot or an icon, a title, an optional description and a mono meta on the right. selected makes it a menuitemradio; danger paints it red. The account menu in the topbar uses the same .menu-item styles.

<DropdownMenu open={open} onClose={() => setOpen(false)} aria-label="Status">
  <MenuItem dot="var(--color-team-implementation)" title="Live" description="Operating normally" meta="1,204" selected={s === 'live'} />
  <MenuItem dot="var(--color-team-compliance)" title="In attention" meta="38" selected={s === 'att'} />
  <MenuSeparator />
  <MenuItem title="Closed" danger />
</DropdownMenu>

StageProgress

The step strip in a table row: one 18×3 segment per step, 3px apart. Done steps are green, the current one accent (amber when late), the rest on the track. The accessible name states the step and whether it is late; pass label to translate it.

<StageProgress steps={6} current={4} late label="Etapa 4 de 6, atrasada" />
