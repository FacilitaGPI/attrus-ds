Design system SelectableCard TSX

SelectableCard

Um card que é o controle: a superfície inteira é o alvo de clique. Substitui a composição manual .card + .radio que todo fluxo de onboarding e KYC reinventava — cada um com seu próprio padding, raio e estado selecionado.

Stable
Import
const { SelectableCard, SelectableCardGroup } = ATTRUS
CSS class
.sel-card
Variants
  • default — pick-one, marcador redondo (radio)
  • .sel-card-multi — pick-many, marcador quadrado (checkbox)
  • .sel-card-sm — denso — padding e tipo menores
  • .on-inverse — superfície escura permanente
Key props
  • title — linha primária (obrigatória)
  • desc — copy de apoio
  • index — chip de índice — "01"
  • selected / onSelect — estado controlado
  • multi — semântica de checkbox
  • name — agrupa radios
  • disabled — estado travado
  • size — 'md' | 'sm'
  • onInverse — tratamento escuro
Prefer: este componente sempre que o usuário escolhe entre opções descritivas (tipo de conta, plano, método, jurisdição). Não recomponha com .card + .radio, e não use .toggle-chip quando há descrição — chip é para rótulo curto.

01Anatomia

Índice opcional, corpo (título + descrição) e marcador de seleção. O <label> envolve um input escondido, então clique e teclado funcionam nativamente.

Pick one .sel-card

Marcador redondo, semântica de radio. Agrupe com name.

radio

02Pick many

A variante .sel-card-multi troca o marcador para quadrado — o sinal universal de "pode escolher mais de um".

Multi .sel-card-multi

Semântica de checkbox. Combine com .sel-card-group.is-grid para grade auto-fit.

checkbox

03Tamanho e estados

Denso para listas longas sem descrição; disabled usa tokens explícitos (superfície sunken + texto disabled), nunca opacidade.

Dense .sel-card-sm

Padding e tipo reduzidos — bom para moeda, jurisdição, período.

size

Disabled [aria-disabled]

Selecionado + travado permanece distinguível do não-selecionado + travado — o bug que a opacidade causava.

state

04On inverse

Em hero e onboarding permanentemente escuros, .on-inverse troca superfície, borda e marcador para a camada accent — sem sobrescrever cor inline.

Dark surface .on-inverse

O estado selecionado usa --color-accent-solid em vez do brand sólido, que somiria no ink.

inverse
