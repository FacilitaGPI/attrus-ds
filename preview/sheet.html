Sheet

The panel that rises from the bottom edge on a phone, within thumb reach. Use it where a wide screen would open a drawer, a modal or an inline panel: a row's detail, a sort, a set of filters. It is a dialog in full — named by its title, focus moves in and is trapped, Esc and the scrim close it, focus returns to what opened it and the page behind stops scrolling. DTDetailSheet is a Sheet with the detail layout.

API

<Sheet
  open={boolean}
  onClose={() => void}
  title="Sort by"            // names the dialog (aria-labelledby)
  sub?="…"                        // supporting line under the title
  eyebrow?={<Pill/>}             // above the title — status on a detail
  footer?={<><Button/><Button/></>}  // two actions, secondary · primary
  closeButton?={true}             // the ✕ in the header
  dismissible?={true}             // Esc and scrim close; false for a required flow
  initialFocus?={ref}             // default: the .is-on option, else the first control
>
  {content}
</Sheet>

Three uses, one component

Tap a row, the sort icon or the filter icon. Try the keyboard too: focus enters the sheet and stays in it, Esc closes it and focus goes back to the control that opened it.
