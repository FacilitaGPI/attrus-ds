01When to use

Two roles, same component. Choose based on what the user is trying to do.

Listing

The user is picking one item from a known dataset — a counterparty, an internal account, a currency, a country. Replaces a Select when options > ~10 or when fuzzy search matters.

Smart searchbar

The user is orienting themselves — they might want an action, a record, a doc, or to jump to a screen. The combobox guides: suggests, groups results, recognises IDs, recovers from typos.

Don't use for…

Multi-select (use multi-pick or chip-input), free-form text (use input), or yes/no decisions (use toggle / radio).

03Anatomy

Both modes share the same six pieces — only the body content swaps.

  1. Input row — leading icon (search / spinner), placeholder, optional clear (×) button. Always 36–40 px tall.
  2. Group label — uppercase tracking-wide eyebrow that introduces each section (Suggestions, Recent, Actions, API, FAQ, Result). Use --color-foreground-muted.
  3. Body content — chips (suggestions), list rows (results, recent searches), type-picker buttons (ID disambiguation), illustrations (empty / loading / error).
  4. Result-label slot — small eyebrow saying "Result (0)" or "Result" used in similar-match, no-results, ID search and error states. Separates "what we searched" from "what we got".
  5. Hint card — a translucent help block inside the body for did-you-mean copy, ID format reminders or contextual tips. Uses --color-background-subtle + a help-circle icon.
  6. Footer — sticky row with keyboard shortcuts: ↑↓ Navigate · ↵ Open · esc Close.

04Empty & placeholder

The two states a build needs before the happy path: what the trigger looks like before a choice, and what the list says when a search finds nothing.

Placeholder — before a choice

Muted text stands in for the value at the same weight as a real one, so only colour separates them and the trigger keeps its shape whether filled or empty.

No results — search finds nothing

The zero-state names what was searched, and the footer action stays reachable — so a search that fails becomes the fastest path to creating the record.

No counterparty found Nothing matches “Zyx Holdings”.

Disabled and invalid

.is-disabled drops the trigger to a subtle surface; .is-invalid borrows the danger border and swaps the focus ring, so the error survives focus instead of being hidden by it.

06For agents

A combobox fills a field. That single sentence resolves most of the wrong choices below — the component is a form control, not a way to search the product.

Use when

All three must hold: the choice writes into a field, the list is long enough that scanning fails (roughly 8+ options), and exactly one value is selected. Fail any one and something else is the right component.

Use instead

WhenUse
Under ~5 fixed optionsNative <select> — it gets platform keyboard, mobile wheel and zero JS for free. A combobox here is more code for less behaviour.
Searching across entities, not filling a fieldSmartSearch — it portals over the page and takes focus, which is correct for navigation and wrong for a field, since it covers the very input being filled.
More than one valueToggleChip group — selected state stays visible without a popover, so the user sees all choices at once.
Options need a description to choose betweenSelectableCard — an option row truncates; a card gives the description room.
Free text with suggestionsPlain Input with a suggestion list. A combobox commits a value from a closed set; it is not an autocomplete for arbitrary text.

Anti-patterns

Do notWhy it fails
Render .combobox-popover inline inside a scrolling ancestorIt gets clipped by any overflow in the chain. The TSX portals it to <body> for exactly this reason — static is for doc galleries, not production.
Use it as a picker inside a Drawer or Modal without checking layeringThe popover sits at z-index: 9200 to clear the scrim (9000) and drawer panel (9100). Reparenting it under a different stacking context loses that.
Copy the footer markup expecting keyboard navigationThe kbd chips are labels. Arrow keys, Enter and Esc live in the TSX; rendering the classes yourself buys the appearance of behaviour, not the behaviour.
Leave aria-activedescendant off a CSS-only buildThe visual .is-active highlight moves while the screen reader announces nothing — the list becomes unusable without sight.
Put a disabled option in the middle of a list without .is-disabledArrow navigation walks a filtered selectable array. A disabled row that is not marked becomes a dead stop in the keyboard path.
Swap .is-invalid for a red border of your ownThe class also changes the focus ring to danger. A hand-rolled border is overpainted by the default focus ring, so the error disappears exactly when the user is fixing it.
Use .combobox-avatar and expect the TSX to emit itIt does not — the class exists in the CSS but no prop renders it. Pass it in your own trigger content, or the identity tile silently loses its styling.

Rules

RuleReason
One combobox open at a timeTwo portalled popovers at the same z-index resolve by DOM order, not by which one the user opened.
Turn on searchable above ~8 optionsBelow that the search row costs more height than it saves scanning.
Popover caps at 320px (~7 rows)Past that the user scans instead of reading, and the popover starts covering the field it belongs to.
Trigger stays --control-h-md (40px)It must line up with inputs and buttons on the same row; the height comes from the shared control scale.
Never nest interactive content in an optionThe row is the control. A button inside it needs stopPropagation and still breaks arrow navigation.

08Class map

Every class the component ships, and what it owns. If a class is in combobox.css and not here, one of the two is wrong.

Trigger

ClassRole
.comboboxRoot. Establishes the positioning context and carries .is-open, .is-disabled, .is-invalid.
.combobox-triggerThe field itself — --control-h-md, so it lines up with inputs and buttons on the same row.
.combobox-trigger-iconLeading icon slot, --icon-sm.
.combobox-avatarIdentity tile, --control-h-xs. Not emitted by the TSX — pass it in your own trigger content.
.combobox-valueSelected label, truncates.

.combobox-chevronDisclosure glyph. Rotation is driven by .is-open on the root — it is not a button.

ClassRole

ClassRole
