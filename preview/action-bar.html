Design system

ActionBar

Faixa de ação persistente: ação primária à direita, secundária/voltar à esquerda, contexto (progresso, contagem, aviso) no meio. Fica em --glass-chrome, então acompanha o tema.

Stable
Import
const { ActionBar } = ATTRUS
CSS class
.action-bar
Variants
  • default — 52px, glass chrome + hairline superior
  • .is-fixed — fixada no rodapé da viewport
  • .action-bar-sm — densa
  • .on-inverse — superfície escura permanente
Key props
  • lead — cluster esquerdo — voltar/secundária
  • context — progresso, contagem, aviso
  • actions — cluster direito — primária
  • fixed — fixa na viewport
  • size — 'md' | 'sm'
  • onInverse — tratamento escuro
Prefer: alinhar o cluster direito com .action-bar-actions { margin-left:auto }. Nunca use um spacer flex:1 — um spacer competindo com um Stepper na mesma linha colapsa o Stepper (foi exatamente assim que os rótulos passaram a se sobrepor).
