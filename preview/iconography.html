Library: Lucide 0.469 via CDN · stroke-width 1.75 · default size 16–20 px.
Use <i data-lucide="{name}"> and call lucide.createIcons(). Do not hand-draw SVGs — the only exception is the country flags in assets/flags/.
Stroke — set once, by the DS. Every Lucide icon takes --icon-stroke 1.75, inside a DS component or not; at 12px and under it takes --icon-stroke-thin 1.5. A base rule in colors_and_type.css rewrites only the library default (stroke-width="2"), so do not pass strokeWidth unless you want a different weight on purpose — a check at 3, a large hero glyph at 1.5. Use --icon-stroke-bold 2 for close buttons and indicators where weight matters.
16 · 1.75 14 · 1.75 12 · 1.5
Colour. An icon that accompanies text takes the text colour (currentColor). A secondary action beside a value — copy, open, view detail — takes --color-foreground-icon-subtle (neutral-400, ~3.1:1, just above the 3:1 floor for a UI icon) and darkens to default on hover, so it does not compete with the value. A status icon takes its tone (--color-feedback-*-foreground). On a 1× display a stroke thinner than 1px only gets lighter and blurrier, so it is the colour, not the stroke, that makes a small icon recede.
