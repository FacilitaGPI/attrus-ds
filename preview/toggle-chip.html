Design system

ToggleChip

Um chip que é controle de formulário. Existe porque .chip é um token removível (traz .chip-x) e .pill.interactive é status pill — nenhum dos dois é seleção.

Stable
Import
const { ToggleChip, ToggleChipGroup } = ATTRUS
CSS class
.toggle-chip
Variants
  • default — 32px, rótulo + contador opcional
  • .toggle-chip-sm — denso, 26px
  • .on-inverse — superfície escura permanente
Key props
  • children — rótulo
  • icon — ícone à esquerda
  • count — contador à direita
  • pressed / onToggle — estado controlado → aria-pressed
  • disabled — travado
  • size — 'md' | 'sm'
  • onInverse — tratamento escuro
Prefer: este componente para seleção (filtros, tags, preferências). Use .chip só para tokens removíveis e .pill só para status não-interativo. Quando a opção precisa de descrição, suba para SelectableCard.
